Target site: https://promo.sktukrides.com/
Reference strategy: ../tuk-rides-seo-contents/International-SEO-Roadmap-SK-Tuk-Rides.txt
Scope: Only the promo / middleware SEO website

Goal
Make promo.sktukrides.com the strongest search entry point for foreign visitors searching for tuk tuk rental in Sri Lanka.
The site must win on:
- relevance
- trust
- content depth
- technical SEO
- user experience
- conversion rate

Execution rules
- Do not skip tasks by assumption.
- Do not add pages that repeat the same intent.
- Every page must target one primary search intent.
- Every new page must have unique title, meta description, H1, internal links, FAQ, and CTA.
- All content must be written for foreign travelers.
- Keep the promo site focused on discovery and lead generation.
- Main site booking flows are out of scope unless a promo-page needs a link to them.

Priority order
P0 = must do first

P2 = expansion
P3 = ongoing

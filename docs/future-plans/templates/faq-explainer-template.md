# FAQ Explainer Template

## Goal

Turn one important question into a short, shareable post that also supports the matching page.

## Working Title

`FAQ: {{question}}`

## Hook

`A lot of travelers ask this before booking, so here is the short answer.`

## Structure

1. Ask the question.
2. Give the short answer immediately.
3. Explain the context in plain English.
4. Mention one practical next step.
5. Link to the matching page.

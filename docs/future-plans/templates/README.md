# Reusable Content Templates

These templates are meant for social posts, community replies, and short-form content.

## Files

- [cost-comparison-template.md](cost-comparison-template.md)
- [route-map-template.md](route-map-template.md)
- [faq-explainer-template.md](faq-explainer-template.md)

## Usage

- Use one template per post.
- Keep one primary intent per post.
- Link or mention only the matching page.
- Reuse the same structure across Reddit, Instagram, Facebook, TikTok captions, and YouTube descriptions.
